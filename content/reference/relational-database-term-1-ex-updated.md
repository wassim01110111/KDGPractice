#### Exercise 5

**a.** Explain the error in each case:

```sql
SELECT employee_id,project_id,hours;
SELECT * FROM TASK;
SELECT department_id, manager_id, start_date
FROM DEPARTMENTS;
```

<summary>***Show solution***</summary>

```sql

```

```sql

-- => Missing a comma (,) between salary and department_id, must separate all attributes by commas
```

</details>
